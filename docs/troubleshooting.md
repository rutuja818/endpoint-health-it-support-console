# Troubleshooting Playbook

## Internet not working

1. Check local IP configuration.
2. Check gateway reachability.
3. Check DNS resolution.
4. Check external connectivity.
5. Document the result.

## High CPU

1. Identify top CPU-consuming processes.
2. Determine whether the usage is expected.
3. Check recent software changes.
4. Restart only when appropriate.
5. Record the resolution.

## Low disk space

1. Confirm disk usage.
2. Identify large files/directories.
3. Remove only approved temporary data.
4. Recheck free space.
5. Document the change.

## Application not responding

1. Check process state.
2. Review application logs.
3. Check available system resources.
4. Restart the application if appropriate.
5. Document the result.
