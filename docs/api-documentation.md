# API Documentation

FastAPI automatically provides interactive documentation at:

`/docs`

Main routes:

- `GET /api/endpoints`
- `POST /api/endpoints`
- `GET /api/endpoints/{id}`
- `POST /api/health/check`
- `GET /api/health/endpoint/{id}`
- `GET /api/tickets`
- `POST /api/tickets`
- `PUT /api/tickets/{id}`
- `POST /api/tickets/{id}/logs`
- `GET /api/dashboard/summary`
- `GET /api/dashboard/reports`
- `POST /api/auth/login`
